# Border Radii Tokens — ComplyWise Design System

## Radii Scale

- **radius-full (9999px)**:
  - Used on: All buttons (`+ Add Widget`, `Create a Report`, `+ Add Member`), segmented pills (`Dashboard`, `Compliance`, `Reports`), date selector, user avatars, action pills (`3 actions`, `+32%`, `★ IS 3055`).
- **radius-3xl (24px - 28px)**:
  - Used on: Outer application window (`rounded-3xl` / 28px), dashboard cards (`rounded-3xl` / 24px).
- **radius-2xl (16px - 20px)**:
  - Used on: Active sidebar item container, internal sub-cards, chart bar caps.
- **radius-xl (12px)**:
  - Used on: Sidebar icon boxes, dropdown menus, modal panels.
- **radius-sm (6px - 8px)**:
  - Used on: Small inline badges and micro-tooltips.

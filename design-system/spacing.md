# Spacing Tokens — ComplyWise Design System

## Spacing Scale

- **space-1 (4px)**: Micro spacing, avatar overlap, inline badges
- **space-2 (8px)**: Internal button gap, icon-to-label spacing
- **space-3 (12px)**: Card internal margins, pill paddings (`px-3 py-1.5`)
- **space-4 (16px)**: Standard card padding, grid gap on compact viewports
- **space-5 (20px)**: Primary card internal padding, large section gap
- **space-6 (24px)**: Outer window padding, grid gaps between major dashboard cards
- **space-8 (32px)**: Header to content vertical separation

## Grid Architecture
- **Sidebar Width**: 240px fixed on desktop (15.5% of 1536px target canvas)
- **Top Bar Height**: 72px fixed
- **Main Content Max-Width**: Fluid inside outer frame with 24px-32px padding
- **Card Gaps**: 18px horizontal and vertical gaps

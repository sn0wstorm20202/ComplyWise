# Typography Tokens — ComplyWise Design System

## Font Family
- **Primary Family**: Plus Jakarta Sans / Outfit (`var(--font-sans)`)
- **Fallback**: system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif
- **Characteristics**: Geometric circular grotesque; circular 'C', 'o', single-storey circular 'a', tall clean cap-height.

## Typographic Hierarchy

| Level | Size | Weight | Line Height | Tracking | Usage |
|---|---|---|---|---|---|
| Display Hero | 32px / 2rem | 700 (Bold) | 1.15 | -0.025em | Big numbers (`18`, `82%`, `186`) |
| Page Title | 26px / 1.625rem | 600 (SemiBold) | 1.2 | -0.02em | "Compliance Dashboard" |
| Card Heading | 16px / 1rem | 600 (SemiBold) | 1.25 | -0.01em | "Compliance Activity", "Documents", "Compliance Actions" |
| Subheading | 13px / 0.8125rem | 500 (Medium) | 1.3 | normal | "Open Actions", "Total Documents", "Stay Compliant" |
| Body / Stat | 12px / 0.75rem | 500 / 600 | 1.35 | normal | Navigation items, pill labels, chart days |
| Caption / Micro | 11px / 0.6875rem | 400 / 500 | 1.4 | +0.01em | Breadcrumbs, card footers, percentage delta |
